Многие гиганты строят свои публичные API и внутренние сервисы именно на принципах REST.

- **NASA и Disney**: Используют REST API для управления контентом. Например, NASA с помощью REST API распространяет обновления о миссиях на сайты, в мобильные приложения и на партнерские платформы, а Disney использует аналогичный подход для более чем 60 своих веб-ресурсов 
- 
- **Netflix**: Хотя Netflix активно использует GraphQL для некоторых внутренних задач, исторически их API для стриминга на множество устройств (от игровых консолей до Smart TV) был построен на REST. Они используют API-first подход для обеспечения работы сервиса на более чем 1000 микросервисах . В 2008 году открытие REST API позволило Netflix резко увеличить количество подписчиков и интегрироваться с множеством устройств .
### Электронная коммерция и финансы

В этих сферах REST API критически важны для интеграции с партнерами и обработки транзакций.

- **Shopify и PayPal**: Shopify использует API для интеграции с платежными системами вроде PayPal, чтобы продавцы могли принимать оплату. Кроме того, Shopify предоставляет собственный REST API для управления магазинами, товарами и заказами.
- 
- **Банки (например, Bank of America, Citi)**: Крупные финансовые учреждения используют REST API для предоставления клиентам доступа к их счетам, переводам и другим банковским операциям через мобильные приложения и сторонние сервисы .
### Публичные сервисы и данные

Огромное количество открытых данных доступно через REST API.

- **Google Maps, Twitter (X), YouTube, GitHub**: Это одни из самых известных публичных REST API. Разработчики используют их для встраивания карт, отображения постов, видео и управления репозиториями кода .
- 
- **Государственные услуги**: Например, в Великобритании DVLA (агентство по лицензированию водителей и транспортных средств) использует API для управления данными о более чем 47 миллионах водителей, а правительство Бахрейна предоставляет через API доступ к более 300 государственным услугам .
